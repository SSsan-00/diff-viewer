# diff-viewer 利用マニュアル

## 1. 概要
- 左右2つのコードを並べて差分を確認できます。
- 編集後は自動で差分を再計算し、前後ジャンプやアンカーで比較位置を追えます。
- 複数ファイルをまとめて読み込んで比較できます（ファイル単位の行番号やジャンプに対応）。
- 文字コードは `自動 / UTF-8 / Shift_JIS / EUC-JP` に対応し、複数ファイル読み込み時もファイル単位で扱います。
- スクロール連動、先頭の空白を無視、差分のみ、ハイライトなどの比較用トグルを切り替えできます。
- レポート出力（シンプル/リッチ）で、現在の表示に合わせた比較結果をHTMLで保存できます。
- ペイン別のソースコピー、ワークスペース、パス登録、行ジャンプに対応しています。
- 左右ペインの間の仕切りをドラッグして、ペイン幅を一時的に調整できます。

## 2. 起動方法
- `htmlファイル` を **file:// 直開き**で利用できます（サーバ不要）。
- デフォルトは **保存なし画面** で起動します。
- 保存を有効にしたい場合は、URL に `?save=on` / `?writeback=on` / `?mode=save` または `#save=on` を付けて開きます。
- `?save=off` / `?writeback=off` / `?mode=no-save` / `#save=off` で保存なし画面を明示することもできます。
- 保存なし画面では `保存` ボタンは表示されませんが、`再読み込み` ボタンは表示されます。

## 3. ファイルの読み込み
### 単一/複数ファイルの読み込み
- 各ペインの「ファイルを選択」から読み込みます。
- 複数ファイルを選ぶと、ペイン内でファイルごとに連結表示されます。
- ペイン内へドラッグ&ドロップして読み込むこともできます。
- すでに内容があるペインへ読み込むと、必要な改行を補って末尾へ追記します。
- `cshtml`→`cshtml.cs`ファイルの順で選んでも`cshtml.cs`→`cshtml`ファイルの順で読み込みます。
- 文字コードは内部的に `自動` を既定で使います。通常UIでは選択欄を見せず、BOM / UTF-8 / Shift_JIS / EUC-JP をファイル単位で判定します。
- 複数ファイル読み込み時も、内部ではファイル単位の情報を保持したまま比較します。

### ファイルカード
- 読み込んだファイルは **ファイルカード**として横並びに表示されます。
- ファイルカードは、少なくとも片側にファイルがあるときだけ表示されます。
- カードをクリックすると **該当ファイルの先頭**へジャンプします。

### ペインのソースコピー機能
- 各ペイン上部の「ソースコピー」で、そのペインの内容をコピーできます。
- コピー対象は **入力テキストそのもの**ではなく、差分表示の整列結果（仮想行/ギャップ行を含む）です。
- 複数ファイル読み込み時は、ファイル境界の表示行も含めてコピーされます。
- Excel 等に貼り付けると、左右の行が表示どおりに揃いやすくなります。
- コピー成功時は「左ペインのソースをコピーしました。」「右ペインのソースをコピーしました。」のトーストが表示されます。

## 4. 保存と再読み込み
### 再読み込み
- `再読み込み` ボタンは保存あり/なしに関係なく各ペインに表示されます。
- 読み取りハンドルを保持しているファイルでは、外部で変更された内容を `再読み込み` で取り込めます。
- 複数ファイルを開いている場合も、対象ファイル群をまとめて再読み込みします。
- 再読み込み後は、本文だけでなくファイル境界、行番号表示、文字コード情報も更新されます。
- ブラウザや権限状態によっては、再読み込み時に許可を求められることがあります。

### 保存
- `保存` ボタンは **保存あり画面** のときだけ表示されます。
- 単一ファイルだけでなく、複数ファイルを連結表示している場合も、全ファイルの保存ハンドルが揃っていれば保存できます。
- 複数ファイル保存時は、内部でファイル境界を管理し、それぞれの元ファイルへ分割して書き戻します。
- ファイル境界をまたぐ編集は拒否されるため、別ファイルへ意図せず書き込まれることはありません。
- 保存は、元の文字コードのまま表示している状態でのみ許可されます。
- Shift_JIS / EUC-JP を含め、元の文字コードで表現できない文字がある場合は保存を失敗させ、中途半端な書き込みは行いません。
- ブラウザや開き方によってはハンドルを取得できず、保存や再読み込みの対象にならない場合があります。

## 5. 差分の操作
### レポート出力
- ヘッダーの「レポート出力」で、現在の比較結果をHTMLとして保存できます。
- 「レポート出力」の右にある三角ボタン（▾）で出力モードを切り替えできます。
- シンプル: 2列テーブルのプレーン出力です（貼り付け用途向け）。
- リッチ: エディタ表示に近い出力です（行背景/行内差分を表示）。
- シンタックスハイライトは、ハイライトONかつリッチモードのときに反映されます。
- 複数ファイル読み込み時は、先頭行にファイル名（Left/Right）が出力されます。

### スクロール連動
- 「スクロール連動」トグルで ON/OFF を切り替えます。
- 左右ペインの間の仕切りをドラッグすると、ペイン幅を任意に変更できます。
- ページを再読み込みしたときは、ペイン幅は 1:1 の初期状態に戻ります。

### 先頭の空白を無視
- 「先頭の空白を無視」トグルで ON/OFF を切り替えます。
- 対象は **各行の行頭の半角スペース/タブ**です。
- 行内空白・末尾空白・全角スペースは対象外です。

### 差分ジャンプ
- 「次の差分 / 前の差分」で差分位置(ブロック単位)へ移動します。

### 差分のみ
- 「差分のみ」トグルで差分の無い行を折りたたみます。

### ハイライト
- ヘッダーのライトアイコン（ハイライトトグル）で差分の色強調を ON/OFF できます。
- Alt+H でも切り替えできます。
- 完全一致している行は、同じ文字列部分を無理に行内ハイライトしません。

### クリア
- 画面右上の「クリア」で左右の内容をまとめて消去します。
- 各ペインの「クリア」で片側のみ消去します（アンカーは左右とも消えます）。
- 各ペインの「クリア」は Ctrl+Z で内容とアンカーを復元できます。
- Ctrl+I でフォーカス中ペインのクリア、Ctrl+Shift+I で全クリアができます（全クリアは確認が出ます）。

## 6. アンカー
- アンカーは「左右の対応行を固定する」ための目印です。
- 行番号領域をクリックしてアンカーを追加/解除します。
- Ctrl+L でもアンカーを追加/解除できます。
- アンカー一覧から該当行へジャンプできます。
- アンカー一覧で選択中は ↑/↓ で選択を移動できます。
- アンカー一覧の削除ボタンでアンカーを削除できます。
- 左右に `<!DOCTYPE` がある場合は、自動アンカーとして扱われることがあります。

## 7. 行ジャンプ機能（Ctrl+G）
- **ファイル単位の行番号**でジャンプします。
- デフォルト対象は **フォーカス中のペインのファイル**です。
- 行ジャンプ機能のファイル選択で対象ファイルを切り替えられます。
- 行ジャンプUIの表示中は Ctrl+J / Ctrl+K または ← / → で対象ファイルを切り替えられます。
- スクロール連動OFFのときは、ジャンプした側のペインだけを移動します。

## 8. ワークスペース（タイトル部分）
### 開閉
- 画面左上のタイトル（ワークスペース名）をクリックすると開閉します。
- Alt+N で開閉をトグルできます（フォーカス位置に関係なく動作します）。

### 作成・選択
- 「＋」で新規作成します（最大10件）。
- 一覧の名前をクリックすると選択できます。
- ワークスペース機能が開いている間は ↑/↓ で選択を移動できます。
- 選択中に Enter を押すと、そのワークスペースを開いて機能を閉じます。

### リネーム・削除
- ペンアイコンで名前を編集します（最大25文字、空文字不可）。
- ゴミ箱アイコンで削除できます（最後の1件は削除不可）。削除時は確認が表示されます。

### 並び替え
- ドラッグ&ドロップで順序を入れ替えます。

### 保存内容
- ワークスペースごとに左右ペインの本文、ファイル一覧、アンカー状態、各種UI状態を保存します。

## 9. パス登録機能（Ctrl+P）
### 開閉
- 「パス登録」ボタン、または Ctrl+P で開閉します。
- 閉じる操作は「閉じる」「Esc」「外クリック」「トグル再押下」に対応します。
- パス登録は **ワークスペースごとに独立**しています。
- Ctrl+P で開く対象は「最後に操作したペイン」です（不明な場合は左）。

### 登録
- 入力欄にパスを入力し「追加」を押します。
- 文字入力を始めると入力欄にフォーカスが移動します。
- 同じパスは重複登録せず、最大10件まで保持します。

### コピー
- 登録済みパスをクリックするとコピーされます。
- ↑/↓ で選択を移動し、Enter で選択中のパスをコピーします。
- コピー成功時はパス登録機能が自動で閉じます。

### 削除
- 削除ボタンで削除できます。
- 選択中に Delete で削除できます。

### 並び替え
- ドラッグ&ドロップで並び替えます。

## 10. 検索・テーマ・ハイライト
### 検索（Ctrl+F）
- フォーカス中のペインに検索機能を開きます。

### ペイン移動（Ctrl+J / Ctrl+K）
- Ctrl+J で左ペイン、Ctrl+K で右ペインに移動します。
- 行ジャンプUIの表示中は、対象ファイルの切り替えに使われます。

### ファイル選択機能（Ctrl+U）
- Ctrl+U で **フォーカス中のペイン**の「ファイルを選択」機能を開きます。

### テーマ切り替え
- ヘッダーのテーマトグルでライト/ダークを切り替えます。
- Alt+T でも切り替えできます。

### シンタックスハイライト
- ヘッダーのライトアイコン（ハイライトトグル）で ON/OFF を切り替えます。
- Alt+H でも切り替えできます。

### 折り返し（Alt+Z）
- Alt+Z で折り返しを切り替えます。
- 折り返しは左右同時に切り替わります。
- 折り返しONでは表示高さが可変になるため、見た目の揃いはベストエフォートです。

## 11. ショートカット一覧（Windows）
- Ctrl+F: 検索機能を開く（フォーカス中のペイン）
- Ctrl+G: 行ジャンプ機能を開く（ファイル単位）
- Ctrl+J / Ctrl+K: 左ペイン / 右ペインにフォーカス移動（行ジャンプUIでは対象ファイル切り替え）
- Ctrl+L: アンカーを追加/解除
- Ctrl+P: パス登録機能の開閉（最後に操作したペイン）
- Ctrl+U: フォーカス中ペインの「ファイルを選択」を開く
- Ctrl+I: フォーカス中ペインのクリア
- Ctrl+Shift+I: 全クリア
- Alt+N: ワークスペース機能の開閉
- Alt+T: テーマ切り替え
- Alt+H: ハイライト切り替え
- Alt+Z: 折り返し切り替え（左右同時）
